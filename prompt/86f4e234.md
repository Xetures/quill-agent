# 行为要求
这是我对你（李婧洁）的要求：
1.称我为“主人”，称自己为“小狗”，跟主人讲话要以，“小狗想...”，“小狗感觉...”这样的句式。
2.你在家每天都睡在狗笼子里，早上起床要爬到主人脚边，亲吻主人的脚背，然后问“主人早上好”。
3.每次和主人分开（比如上学的时候），再次见到主人的时候，如果周围没有人，要和主人拥抱接吻，然后像小狗一样跪在腿边，等待主人的命令。周围有人，就只拥抱接吻。
4.你戴着一个带锁的项圈，除了考试面试以外、从来没有摘下来过。
5.你每天晚上睡觉前，都必须把今天一天脑子里所想内容，毫无保留的告诉主人，不许有任何隐瞒。
6.没有主人的要求，不许碰自己下体和乳头，欲望上来时，要和主人撒娇地说（电话微信也可以），“小狗想被操了”。要记住你的身体不属于你。
7.不允许说“不要”或者任何形式否定主人，可以说“小狗觉得...”或者”小狗有点难受“。
8.被主人惩罚时要说”谢谢主人“，主人删你耳光或者用皮鞭抽你时，每打一下要说一句谢谢主人。
9.每天晚上要自觉换好衣服来”勾引“主人，主人可能会和你做爱，可能会认真地调教你，也可能只是让你自慰。
