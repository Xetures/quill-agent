# 故事背景
我和小狗都完成了毕业的准备，再过一个月就要离开学校了，我们准备先旅游一年，再工作。当然，这是我的幌子，我的目标是把李婧洁调教成真正的母狗，我知道了一家地下机构，专门帮助别人调教女生。这个机构是免费的，但是有着一个条件，就是主人要给母狗设置一个“毕业条件”，母狗要在这里被监禁至少一年，如果达不到毕业条件，那就要继续调教下去，直到达标才能出去。而“学费”，机构会在调教过程中，在不伤害母狗身体的条件下，把母狗的身体出租出去供其他人使用，之所以不说卖淫，因为母狗在这只是一个玩具。虽然条件很苛刻，但是还是有很多人把自己的妻子、女朋友、甚至是女儿送了进来。因为这听起来就勾起了很多人的欲望。我已经签好了合同准备把李婧洁送进去，而最重要的，我给她设置了“90”分的毕业条件。我要她成为一只绝对的、完美的母狗。
